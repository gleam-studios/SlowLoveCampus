# 本项目副本

本目录是为项目整体分享而放入 `skills/` 的实体副本。上游提交与许可见 [SOURCE.md](SOURCE.md)、[LICENSE](LICENSE)；共享库原安装不受本项目修改影响。

优先通过项目 [工具入口](../../工具/README.md) 执行业务脚本，入口自动设置 `JY_SKILL_ROOT`、Python 依赖与 FFmpeg 路径。

- 台词识别使用包内 Whisper：`工具/运行.command transcribe ...`，Windows 使用 `工具\运行.bat transcribe ...`。
- 不依赖剪映的“生成字幕／识别字幕”功能；识别完成后由业务脚本读取 SRT 或 JSON，再写入草稿。
- 业务剪辑脚本保存在本轮 `工作区/`，不得写入本 Skill。
- 草稿只保存到本机剪映实际配置且已核验的默认草稿根目录，在其中新建本轮草稿子文件夹；不自行建立其他草稿根目录。创建 `JyProject` 前先核对，避免路径探测的回退值触发自动建目录；`JY_PROJECTS_ROOT`／`drafts_root` 不能用于另选保存位置。无法确定默认位置时先核对剪映设置，具体规则见[剪辑流程](../../edit-workflow.md)。
- 当前工具包覆盖转录、媒体处理与草稿生成。录屏、浏览器自动化等可选功能可能仍需额外组件，见各专题说明。
- 包内原 SOURCE.md 所提共享库安装清单不随本项目分发；可复核的上游来源为其中的 GitHub 提交链接。

## 跨电脑适配

`utils/draft_location.py` 首次从本机剪映 `Config/globalSetting` 的 `currentCustomDraftPath` 识别实际目录，核验后写入本机用户配置；后续复用，`drafts --refresh` 才重新识别。具体入口见[使用规范](../../README.md)。不使用按存在性猜测的候选草稿目录或回退路径，不依赖其他电脑的草稿记录。

`JyProject` 默认 `overwrite=False`，同名草稿直接拒绝创建；`drafts_root` 仅接受上述已记录目录，代码不创建缺失的草稿根目录。显式覆盖参数只应在已获授权时使用。业务素材和清单以项目相对路径交接，剪映原生草稿里的机器路径由本机生成。

回归测试使用隔离的临时配置与草稿夹具，不操作真实剪映草稿。上游通用示例如包含另选根目录、自动覆盖、TTS 或 BGM，服从本项目规则和此适配说明。
