# 本项目最小执行步骤

优先执行[项目适配](../PROJECT_COPY.md)与[剪辑流程](../../../edit-workflow.md)。不依赖系统 Python、共享技能库或其他电脑路径。

1. 首次通过 `./工具/运行.command check`（Windows：`.\工具\运行.bat check`）检查工具包并自动识别、记住本机剪映实际草稿目录。之后用 `drafts` 查看记录，用户在剪映改过位置才用 `drafts --refresh`。识别失败时停止，不设置替代 `JY_PROJECTS_ROOT`。
2. 只查看本轮脚本与素材，项目文件用相对路径；外部素材先复制进本轮工作区。
3. 业务脚本保存在本轮 `工作区/.../剪辑/`，通过工具包 `python` 入口运行；环境已提供 `JY_SKILL_ROOT` 和依赖。新草稿名必须唯一，默认不覆盖。
4. 按脚本用 FFmpeg 剪辑、本地 Whisper 识别并校对字幕，再用相同清单生成草稿。草稿只写进已识别并记录的本机目录。暂不配音或添加 BGM。
5. 核对 MP4、字幕和草稿结构；只有在剪映实际打开预览过才声明可打开。

不得通过另建草稿根目录、覆盖其他工程、切换素材或联网补依赖来掩盖错误。
