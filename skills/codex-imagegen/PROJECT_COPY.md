# 项目适配

优先直接使用当前 Codex 会话的原生图片工具，不递归调用本桥接器。桥接器仅在适用的其他执行环境中检查／调用已有 Codex CLI，不保证任意账户的生图能力。

本项目副本将新 `receipt.json` 中的项目图片与日志路径记录为相对 `--workdir` 的路径，`path_base` 为 `project`；不在回执中固化当前电脑的 CLI 安装路径。底层工具的运行时消息属于诊断记录，不作为共享素材引用。

最终图片复制进本轮 `工作区/.../角色参考/` 再交接下游；不得只引用用户目录中的临时生成结果。原始工具协议如要求绝对路径，由运行时解析，不写入业务清单。本机共享技能不受本项目适配影响。
